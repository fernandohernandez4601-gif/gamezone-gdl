## Cómo ejecutarlo

No requiere instalación ni servidor: abre `index.html` con cualquier navegador
(Chrome, Edge, Firefox o Safari). Está construido solo con **HTML5 y CSS3**; los
íconos son archivos **SVG** propios en `assets/icons/`.
